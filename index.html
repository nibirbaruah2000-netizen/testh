Why Fourthnight

Everything a server needs, in one bot

Built for reliability and safety, with configuration that stays separate for each server.

🛡️

AntiNuke

Detects one user doing too many destructive actions and strips their power or bans them.

⚖️

Moderation

Kick, ban, timeout, warnings with automatic thresholds, case logs and channel lockdown.

🪙

Global economy

One balance for every server. Earn, pay friends, rob, deposit and climb the leaderboard.

🛒

Shops and trading

Every server can run its own shop. Buy from any of them and trade items with members.

🎲

Games and fun

Slots, dice, coin flips, rock-paper-scissors, 8-ball and social commands.

🧭

Utility

Polls, reminders, server and user info, avatars, and live bot statistics.
