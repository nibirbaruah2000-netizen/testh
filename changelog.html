Release history

What changed in each version of Fourthnight.

Version 6.0

Latest
2026-10-19
  • Added the open-source attribution line to /help and /botstats.
  • Added AGPL-3.0 license file.
  • Shipped a watermarked build and a clean build.

Version 5.0

2026-10-19
  • Added AntiNuke: detects mass channel/role deletes, bans, kicks and webhook creation.
  • New /antinuke commands for status, toggle, threshold, punishment and allowlist.
  • Invite permissions now include Manage Roles and View Audit Log.

Version 4.0

2026-10-19
  • Renamed the bot to Fourthnight.
  • Fixed a missing dependency (greenlet) that stopped the bot from starting.
  • Added 50 commands: global economy, shop and trading, fun games, utility, and extra moderation.

Version 1.0 – 3.0

  • First working build: moderation with case logs, warnings with thresholds, and per-server configuration.
