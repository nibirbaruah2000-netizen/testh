Self-hosting

Run it on your own machine

You'll need Python 3.11+ and a Discord bot token from the Developer Portal.

  1. Extract the zip and open a terminal in the discord_bot folder.
  2. Run pip install -r requirements.txt.
  3. Copy .env.example to .env and add your DISCORD_TOKEN.
  4. First run only: SYNC_COMMANDS=true python main.py, then start normally with python main.py.

For Docker, see the README included in the zip.
